# 기존 화면 기반 재디자인 — 2026-10-27

상태: **계획·실적 비교, 메인 2D, 좌표 편집·저장, 상세 과거 재생 모두 제품 구현. Figma 반영 대기**.

아래는 시안 설계 이력이다. 서버 저장·권한·재생의 현재 동작은 [제품 구현 명세](2D배치_좌표편집_과거재생_구현.md)를 기준으로 한다.

[독립 디자인 시안](../outputs/조선_AX_화면_재설계.html)은 기존 `work/screen_template.html`의 화면 스타일과 샘플 데이터를 재사용한다. `node work/preview_ui_redesign.mjs`로 `http://127.0.0.1:5303/`에서 연다. 서버 API 호출과 실제 데이터 저장은 수행하지 않는다.

## 최신 결정

| 화면 | 디자인 |
| --- | --- |
| 메인 공정 배치도 | 저장된 구역 좌표로 2D 배치하되 눈금·좌표 숫자·좌표 범례는 숨긴다. 공정·진행 블록·설비 상태와 교육용 개념 배치 안내만 표시한다. |
| Settings → 공정 배치도 수정 | 관리자 편집 화면을 추가한다. 적재된 zones를 모눈 좌표계에서 선택·이동하고 저장할 배치를 확인한다. |
| 조회 탭 | 기존 검색 결과에서 블록·작업·설비 상세로 이동한다. 별도 미리보기 바로가기나 중복 조회 버튼은 두지 않는다. |
| 조회 → 계획·실적 비교 | 조회 탭 내 별도 항목으로 공정·기간·단위, 합계, 일별 및 작업별 내역을 표시한다. 작업번호로 상세에 이동한다. |
| 조회 상세 | 접을 수 있는 과거 이력 조회 패널을 유지한다. 시간 선택·재생·정지·최신 복귀를 체험한다. |

좌표 편집은 원본 명세에 명시된 요구사항이 아니라 **사용자가 이번 대화에서 추가한 요구사항**이다. 앞선 좌표 읽기 전용 및 메인 눈금 표시안은 이 결정으로 대체한다.

여러 작업의 계획·실적 비교 위치는 사용자가 조회 탭 안으로 정했다. 동일 공정·단위 비교는 명세 내용이며 화면의 위치와 표 구성은 대화에서 정한 디자인이다. 시안은 계획일과 실적 집계 종료일을 KST 기준으로 사용하고 미래 계획은 합계·달성률에서 제외한다. 다른 작업의 계획·실적이 같은 기간에 합산될 수 있음을 화면에 명시한다. 조회 → 계획·실적 비교는 실제 제품에 적용했다. 축소 배치도에 구역·공정 코드를 Z03 · P03 형태로 함께 표시한다.

사용자의 후속 요청으로 계획·실적 비교 화면에 메인보다 작은 6구역 공정 배치도를 추가했다. `zones.x/y`의 상대 위치를 축소해 배치하고, 최신 데이터 기준의 공정 상태를 색상과 문구로 표시한다. 구역을 누르면 입력한 조회 기간을 유지하면서 해당 공정과 단위의 비교 결과로 전환한다. 비교 기간에 대한 과거 상태를 나타내는 것은 아니다. 작은 화면에서는 배치도 내부 가로 스크롤을 사용한다.

메인 공정 배치도는 사용자의 후속 요청에 따라 **구역 카드의 테두리만 유지**하고 바깥 패널과 안쪽 지도 테두리·배경을 제거했다. Settings의 편집용 모눈 영역은 유지한다. [화면 구현 잔여 항목 점검](화면_구현_잔여항목_점검_2026-10-27.md)에서 실제 제품 반영 상태를 구분한다.

## Settings 편집 화면

- 기존 Settings 디자인 위에 `공정 배치도 수정` 탭을 추가한다. 시안의 역할·계정 관리와 감사이력 탭은 위치만 유지하며 비활성이다. 실제 제품의 해당 기능을 제거한 것은 아니다.
- 상단에는 적재 데이터 `zones`, 구역 수, 저장 전 변경 건수, `변경 되돌리기`, `배치 저장`을 표시한다.
- 왼쪽은 모눈 편집 영역이다. 구역의 좌상단 점이 X/Y 좌표에 대응하며, X는 오른쪽, Y는 아래쪽이다. 격자 20, 큰 눈금 100은 개념 좌표값이며 실제 길이 단위가 아니다.
- 구역 선택, 드래그, 격자 맞춤 옵션, 방향키 이동을 제공한다. 직접 좌표 입력은 드래그가 어려운 환경의 대안이다.
- 오른쪽 선택 구역 패널은 구역 ID·이름을 읽기 전용으로 보여 주고 X/Y 입력과 `좌표 적용`을 제공한다.
- 하단 변경 내역에서 구역별 기존/변경 X/Y를 비교한다.

## 편집 초안과 저장 흐름

1. CSV로 적재된 데이터에 해당하는 샘플 zones를 편집 초안으로 복사한다.
2. 드래그나 좌표 적용은 초안에만 반영한다. 저장 전 메인 화면에는 기존 배치가 유지된다.
3. `변경 되돌리기`는 마지막 저장된 배치로 돌아간다.
4. `배치 저장`은 시안 메모리의 적용 배치를 갱신한다. 이후 메인/상세의 2D 배치에서 새 위치를 확인할 수 있다.
5. 시안에서는 새로고침하면 샘플 원래 위치로 초기화한다. 원본 CSV/엑셀/JSON과 서버 데이터는 변경하지 않는다.

시안의 저장 기록은 메모리상 변경 전후 좌표 예시이며 실제 감사이력 API에 기록된 것이 아니다. 실제 제품 구현 시에는 관리자 서버 인가, 유한한 숫자와 대상 구역 검증, 좌표만 수정하는 API, 데이터와 변경 전후 감사의 일관된 저장이 필요하다. 원본 CSV 파일을 덮어쓰는 기능은 추가하지 않는다. 카드 겹침 처리·운영 좌표 범위·다중 편집 충돌 정책은 제품 구현 전 정해야 한다.

## 검증과 제약

- 생성 HTML·빌더·시안 스크립트 문법 검사 및 문서 링크 확인.
- 브라우저에서 메인 좌표 배지/눈금 미표시 확인.
- Z01 `(40,60)`을 입력과 드래그로 `(80,100)`으로 변경하는 흐름 확인.
- 저장 전 메인 DOM의 구역 위치는 기존 `left:64px, top:84px`로 유지되고, 시안 저장 후 `left:104px, top:124px`로 바뀜을 확인. 메인 눈금과 좌표 배지는 모두 0개다.
- 되돌리기 후 원래 좌표와 저장 버튼 비활성, Settings 왕복 후 편집 초안 유지, 새로고침 후 샘플 초기화 확인.
- 실제 서버 저장/인가/감사, Figma 레이어, 모든 기기 크기, 카드 겹침 정책 검증은 수행하지 않았다.
