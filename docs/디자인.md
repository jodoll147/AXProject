# 디자인 가이드

## 디자인 목표

현장 운영자가 블록·공정·설비·사건의 상태를 빠르게 훑고, 이상 항목에서 관련 상세로 이동하도록 구성합니다. 숫자와 상태를 우선 배치하고, 색상·아이콘·레이블을 함께 사용해 상태를 구분합니다.

## 화면 구조

### 공통 프레임

- 상단 바에 브랜드, `운영현황`·`조회` 내비게이션, 데이터 최신 기준시각, `운영요약` 진입 버튼을 둡니다.
- 본문 최대 너비는 1,520px이며 좌우 여백을 둡니다.
- 공통 패널, 제목, 상태 배지, 표, 상세 패널을 사용합니다.
- 하단에는 현재 사용하는 엑셀 데이터 원본을 안내합니다.

### 운영현황

- 첫 행의 4개 지표 카드: 금일 계획 중 완료, 기한 도래 미완료, 미해소 사건, 설비 상태.
- 공정 배치도: 6개 공정을 3열 그리드로 표현하고, 선택 시 해당 공정 작업 조회로 이동합니다.
- 주목할 작업: 미해소 사건 또는 지연 작업을 카드로 제시합니다.
- 전체 호선의 작업·사건 관련 현황을 표시합니다.

### 조회와 상세

- 조회 화면은 대상 탭, 호선명 정규식 입력, 날짜 범위, 기간 프리셋, 일반 검색 입력과 표 결과로 구성됩니다.
- 작업은 호선별·블록별로 묶고 여섯 공정 흐름을 작은 상태 칩으로 보여줍니다.
- 표 행은 선택 가능하며, 블록·작업·설비 상세 화면으로 이동합니다.
- 상세 화면은 계획/실적, 사건/조치, 이력, 연결 정보 등 관련 정보를 패널 단위로 그룹화합니다.

### 운영요약

- 규칙 기반 관측 사실과 담당 팀별 확인 요청을 편집 가능한 텍스트 영역으로 나눕니다.
- `요약 복사`는 수정된 내용과 기본 요약을 탭 구분 텍스트로 클립보드에 복사합니다.
- AI 요약 패널은 자리만 마련되어 있고 결과는 표시하지 않습니다.

## 시각 시스템

- 배경은 짙은 남색/회색 계열(`#090d14` 등), 패널은 약간 밝은 어두운 계열을 사용합니다.
- 강조색은 청록/하늘색 계열이며, 경고·완료·고장·품질 상태는 각각 노랑·초록·빨강·보라 계열로 구분합니다.
- 글꼴은 `DM Sans`와 `Noto Sans KR`을 선언합니다. Google Fonts 네트워크 접근이 되지 않으면 브라우저 대체 글꼴이 적용됩니다.
- 아이콘은 `lucide-react`를 사용합니다.
- 상태는 색상만으로 전달하지 않고 텍스트 배지와 아이콘을 병행합니다.

## 반응형과 상호작용

- 1,100px 이하에서 주목 카드와 최신시각 일부 표시를 조정합니다.
- 850px 이하에서 현황 카드/공정 그리드와 요약 레이아웃을 축소하고, 내비게이션은 아이콘 중심으로 전환합니다.
- 560px 이하에서 패널 간격과 제목을 줄이고 상세 패널은 한 열로 배치합니다.
- 표는 최소 너비를 유지하고 가로 스크롤을 허용합니다.
- 버튼, 입력, 표 행에 키보드 포커스 표시가 있습니다. 표 행은 Enter 키로 열 수 있습니다.

## 관련 파일

- `app/frontend/src/App.css`: 공통 프레임, 운영현황, 상세, 요약 스타일
- `app/frontend/src/QueryView.css`: 조회 필터, 표, 상태 칩, 블록 상세 스타일
- `app/frontend/src/App.jsx`: 운영현황/요약/작업·설비 상세의 구성
- `app/frontend/src/QueryView.jsx`: 조회/블록 상세의 구성
- `app/frontend/index.html`: 한국어 문서 언어, 제목, 뷰포트 설정
