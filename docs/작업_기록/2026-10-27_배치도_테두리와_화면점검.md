# 작업 기록: 메인 배치도 테두리 정리와 화면 미구현 점검

## 요청
- 공정 배치도의 작업구역 카드 외부에 중복으로 둘러진 두 테두리를 제거한다.
- 확정 중인 디자인을 기준으로 기능 옵션이 아닌 남은 화면 수정 사항을 다시 점검한다.

## 현재 상태와 근거
- 로컬 디자인 시안의 메인 공정 배치도는 외부 패널과 내부 배치 캔버스에 각각 테두리가 있다.
- 실제 제품의 2D 배치, Settings 배치 편집, 상세 과거 조회 화면은 시안만 있으며 제품에는 미적용이다.

## 수정 방안
1. 구역 카드의 테두리는 유지하고 메인 배치도의 외부 두 겹 테두리와 배경 상자를 제거한다.
2. 원본 명세, 현재 제품 템플릿, 최신 디자인 시안을 대조해 화면 추가·수정만 별도로 분류한다.
3. 시안과 화면 목록을 검증하고 결과·범위를 기록한다.

## 검증
- `node work/build_ui_redesign.mjs`, 빌더·시안 스크립트 및 생성 HTML 문법 검사 통과.
- 브라우저 계산 스타일: 메인 외부/내부 테두리 0px, 배경 투명, 구역 카드 테두리 1px·왼쪽 4px, 카드 6개.
- Settings 편집 지도는 테두리 1px, 모눈 1개, 구역 6개 유지 확인.
- Z03 구역 선택 시 공정 P03 조회 목록으로 이동 확인.
- 첨부된 요구사항에 대한 기존 대조 문서, 사용자 대화와 실제 제품 템플릿의 화면 코드를 확인했다. 원본 엑셀 전체를 이번에 재분석하지 않았다.
- 실행하지 않은 검증: 실제 제품 화면 재실행, 모든 화면 크기, Figma 레이어 검증. 이번 변경은 독립 시안이다.

## 남은 항목과 제약
- 메인 2D, Settings 편집 화면, 조회 상세 과거 시각 UI는 시안만 있으며 실제 제품에 미적용이다.
- 메인 필터 배치와 여러 작업의 기간별 비교 화면은 명세상 표현 방식 확인이 필요하다.
- 서버 운영요약은 범위 제외다. Figma Starter MCP 호출 한도로 이전 작업에서 차단되었으며 이번에는 재호출하지 않았다.

## 결과
- 완료. 사용자 지정 테두리를 시안에서 제거하고 실제 제품에 남은 화면 수정 사항을 별도 문서로 정리했다. 실제 제품 구현 여부는 각 항목에 구분했다.
