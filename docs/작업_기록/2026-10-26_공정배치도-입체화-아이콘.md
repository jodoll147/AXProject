# 작업 기록: 공정 배치도 입체화와 공정 아이콘

## 요청

- 운영현황과 블록 상세의 공정 배치도를 입체적으로 표현하고, 각 공정을 알아보기 쉬운 아이콘을 카드에 표시한다.

## 현재 상태와 근거

- 관련 파일/기능: `work/screen_template.html`, `work/sync_frontend.mjs`, `app/frontend/index.html`
- 현재 동작 또는 문제: 공정 배치도는 평면 직사각형 카드 6개와 연결 화살표로 구성된다. 공정 아이콘은 다른 곳에 있으나 배치도 카드 제목에는 없다.
- 미확인 사항: 좁은 화면에서의 실측 배치는 이번 브라우저 세션에서 직접 확인하지 못했다.

## 수정 방안

1. 기존 HTML/CSS 카드에 윗면 하이라이트, 측면 깊이, 그림자와 마우스 반응을 더한다. 텍스트는 평면으로 유지해 가독성을 지킨다.
2. 이미 정의된 6개 공정 SVG 아이콘을 공정 카드 제목에 넣는다.
3. 템플릿을 실행 프론트엔드에 동기화하고 빌드 및 화면 이동을 검증한다. 데이터/API 계약은 유지한다.

## 변경 파일

- `work/screen_template.html` — 공정 카드의 입체 표면, 깊이, 그림자, 바닥 그리드와 공정별 SVG 아이콘 추가
- `app/frontend/index.html` — 템플릿 동기화로 실행 화면 반영
- `docs/작업_기록/2026-10-26_공정배치도-입체화-아이콘.md` — 요청과 검증 기록
- `docs/작업_기록/README.md` — 작업 기록 목록 갱신

## 검증

- 실행: `npm run build` (`app/frontend`)
- 결과: Vite 빌드 성공, 3개 모듈 변환, `dist/index.html` 생성
- 실행: 로컬 브라우저에서 `#/`와 `#/blk/B001` 화면 확인, Z03 카드 클릭
- 결과: 두 화면의 6개 카드에서 공정 아이콘·입체 깊이 확인, Z03 클릭 시 `#/query?type=wo&proc=P03` 이동
- 실행하지 않은 검증: 좁은 화면 실측은 브라우저 뷰포트 변경 기능을 사용하지 않아 미실행

## 남은 항목과 제약

- 760px 이하 화면에 축소 스타일을 추가했으나 실제 좁은 뷰포트 시각 검증은 남았다.

## 결과

완료. CSS 기반 입체 공정 카드와 6개 공정 SVG 아이콘을 운영현황·블록 상세 배치도에 적용했다.
