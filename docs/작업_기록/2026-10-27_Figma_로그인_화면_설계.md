# 작업 기록: Figma 로그인 화면 설계

## 요청

- 기존 Settings 권한 화면과 함께 사용할 로그인 화면을 Figma에 설계한다.

## 현재 상태와 근거

- Figma `조선 AX Settings 권한 관리`에 관리자·조회자 화면이 있다.
- 프로젝트의 실제 로그인 기능은 아직 구현되지 않았다.
- 미확인 사항: 인증 제공자와 계정 복구 정책.

## 수정 방안

1. 기존 화면 스타일에 맞춰 로그인 기본 및 오류 상태를 편집 가능한 레이어로 설계한다.
2. 시각 검토 후 결과와 실제 구현 여부를 기록한다.

## 검증

- 실행: 기존 Figma 파일 연결 및 작성 도구 호출, 로컬 HTML 시안 생성과 파일 존재 확인.
- 결과: Figma Starter 플랜 도구 호출 한도에 도달해 파일을 수정하지 못했다. 기본·실패 상태의 로컬 시안을 작성했다.
- 실행하지 않은 검증: Figma 레이어 생성·시각 검토, 로그인 기능·인증 API 테스트. HTML 시안의 브라우저 시각 검증도 하지 않았다.

## 남은 항목과 제약

- Figma 도구 호출 한도가 해제되면 기존 파일에 편집 가능한 화면을 추가하고 시각 검토해야 한다. 실제 인증 방식과 계정 복구 정책은 결정되지 않았다.

## 결과

부분 완료. 로컬 화면 시안을 작성했으나 Figma 화면 추가는 호출 한도로 완료하지 못했다.
