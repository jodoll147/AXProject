# 작업 기록: 빈 데이터 화면

## 요청
초기 데이터가 없어도 화면이 표시되도록 수정한다.

## 현재 상태와 근거
샘플 데이터와 명세 엑셀이 없으면 API가 예외를 반환하고 화면 초기화가 중단됐다.

## 수정 방안
샘플 데이터가 없으면 빈 테이블을 반환한다. 명세가 없을 때 일반 화면을 표시하고 명세가 필요한 기능에 안내를 표시한다.

## 변경 파일
- app/backend/Program.cs: 빈 데이터, 원본 상태 및 명세 부재 응답 처리.
- work/sync_frontend.mjs: 명세 부재 시 화면 초기화 허용.
- work/screen_template.html: 명세가 필요한 기능 안내.
- app/frontend/index.html: 화면 동기화 산출물.

## 검증
- 백엔드 Release 빌드 성공, 경고 0개, 오류 0개. 프론트엔드 빌드 성공.
- 샘플 파일 없이 health 응답에서 15개 빈 테이블 및 원본 empty 확인.
- 브라우저 로그인 후 운영현황 0/0과 데이터 없음 표시 확인. 업로드 화면에서 명세 파일 안내 확인.
- 실제 엑셀 데이터가 있는 경우는 파일이 없어 검증하지 못했다.

## 남은 항목과 제약
명세 엑셀이 없으면 데이터 업로드와 담당 입력을 사용할 수 없다.
