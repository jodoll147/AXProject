# 작업 기록: 입력 폼 개선과 잔여 요구사항 진행

## 요청
- 라벨과 입력칸 간격을 개선한다.
- 남은 요구사항을 확인하고 다음 작업을 선정해 수행한다.

## 현재 상태와 근거
- Settings·담당 입력에 폼 간격 규칙이 있었지만 선택 영역의 행간과 라벨/입력칸 여백이 부족했다.
- 이전 엑셀 대조 문서는 로그인·권한·감사 구현 전의 상태였다.
- 작업 상세에서 production_plan 버전·날짜·수량과 기간별 실적 전체를 표시하지 않았다.

## 수정 방안
1. 공통 폼의 라벨·행 간격과 반응형 배치를 개선한다.
2. 기존 대조 문서와 현재 코드를 대조해 잔여 요구사항 및 우선순위를 기록한다.
3. 다음 실행 항목으로 작업 상세의 기준계획·일별 비교·실적 이력을 구현한다.

## 검증
- `npm --prefix app/frontend run build` 성공.
- `node --test work/tests/production_comparison.test.mjs` 4개 통과.
- 템플릿·생성 화면 스크립트 문법 및 문서 목차의 상대 Markdown 링크 검사 통과.
- 브라우저에서 담당 입력과 Settings 확인. 좁은 화면의 입력 열과 라벨 여백을 시각 검증했다.
- `WO008-03`: 계획 164m, 실적 102.5m, 차이 -61.5m, 달성률 62.5%, 증분 41/41/20.5 및 누적 41/82/102.5 확인.
- `WO008-04`: 미래 계획량은 표시하되 실적·차이·달성률은 —, 실적 없음 안내 확인.
- 실행하지 않은 검증: 모든 화면 폭의 시각 검사, 서버 전체 통합 테스트 재실행, 원본 엑셀의 전체 필드·관계 재검사. 이번 변경은 프런트엔드 중심이며 서버 검증은 기존 코드/검증 기록을 근거로 분류했다.
