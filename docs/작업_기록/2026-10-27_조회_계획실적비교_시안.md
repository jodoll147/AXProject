# 작업 기록: 조회 탭 계획·실적 비교 디자인

## 요청
- 여러 작업의 동일 공정·단위 계획/실적 비교를 조회 탭에 배치하는 디자인을 만든다.

## 현재 상태와 근거
- 실제 제품에는 개별 작업 상세 비교가 있으며 여러 작업의 집계 화면은 없다.
- 기존 디자인 시안은 메인·조회·상세·Settings를 포함한다.

## 수정 방안
1. 조회 탭에 기존 목록과 계획·실적 비교 진입을 추가한다.
2. 공정·기간·단위를 명시하고 일별 요약과 작업별 근거를 표시한다.
3. 다른 단위 합산 및 미래 실적 생성을 방지하고 시안 데이터로 검증한다.

## 검증
- `node --check` 및 생성 시안 스크립트 문법 검사 통과.
- 브라우저에서 조회 → 계획·실적 비교, 공정 선택, 일별 및 작업별 표 확인.
- 9/14~9/16 용접 계획 468m, 실적 406.5m, 86.9%를 표시하며 별도 Python 계산과 일치.
- 검사 공정으로 전환하면 단위가 개로 변경되고, 미래 계획은 별도 표기되며 비교 합계에서 제외됨을 확인.
- 시작일이 종료일보다 늦으면 오류 표시. 작업번호 선택 시 WO008-03 상세로 이동 확인.
- 문서 목차와 링크 확인. 전체 기간·모든 데이터 오류·모바일·실제 서버 연동은 검증하지 않았다.

## 남은 항목과 제약
- 실제 제품에는 아직 미구현이며 로컬 시안에서만 샘플을 계산한다. 실제 서버 집계 여부와 화면 적용은 후속 작업이다.
- 동일 공정·단위 비교 기준은 명세, 조회 탭의 위치와 화면 표 구성은 사용자와의 대화에서 결정했다.
- Figma 반영은 기존 Starter MCP 호출 한도로 대기 중이며 이번 작업에서 재호출하지 않았다.

## 결과
- 완료. 여러 작업의 계획·실적 비교를 메인 대신 조회 탭 안에 디자인했다. 실제 제품 및 Figma 반영은 미완료다.
