# 작업 기록: 과거 재생 시안 블록 중심 개선

## 요청
- 이해하기 어려운 주요 사건 중심 화면을 개선하고 블록이 보이도록 디자인한다.

## 현재 상태와 근거
- 기존 시안은 예시 사건 이동 목록과 4개 작업만 보여 블록별 공정을 파악하기 어려웠다.
- 현 제품은 운영현황의 공정 배치도 및 조회 화면의 블록별 공정 흐름을 제공한다.

## 수정 방안
1. 사건 중심 목록·탐색점을 제거하고 15분 전/후 시간 이동으로 단순화한다.
2. 전체 샘플 블록의 6개 공정 현황과 선택 블록 상세를 시안에 추가한다.
3. 선택시각에 따라 블록 상태·실적이 바뀌는지 확인하고 설계 문서를 동기화한다.

- 브라우저에서 블록 12개·6개 공정 표시 및 B007 검사 선택 시 WO007-04, 인정 8/10, INC005 표시 확인.
- B008 용접은 10:15 작업 중·82/164m, 10:30 설비 고장·102.5/164m와 INC003 표시 확인. 선택 블록과 공정은 시각 변경 후 유지됨.
- 최신 12:00 복귀 시 완료 2/6, 기한 도래 미완료 4, 미해소 3 및 B008 선택 유지 확인.
- 브라우저에서 블록 보드와 상세 배치를 시각 확인했다.
- 실행하지 않은 검증: 제품 코드 통합, 모든 화면 크기의 시각 검사, 과거 시각 경계 전체 자동 테스트. 이 작업은 디자인 시안 수정이다.

- 시안의 시간 범위는 샘플 2026-09-16 08:00~12:00이다. 실제 앱 적용 시 전체 관측 범위와 기존 공정 배치도를 유지하도록 설계했다.
- 블록별 공정 표는 생산 진행 현황이며 블록의 실제 물리적 배치도는 아니다.
