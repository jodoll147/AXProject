# 작업 기록: 엑셀 요구사항과 구현 대조

## 요청

- `01_조선_데이터참고명세서.xlsx`의 요구사항 및 기능 요청사항을 현재 프로젝트와 대조한다.
- 구현된 부분과 구현되지 않은 부분을 모두 근거와 함께 보고한다.

## 현재 상태와 근거

- 관련 파일/기능: 사용자 제공 엑셀, 저장소 코드 및 `docs/프로젝트_기능_설명.md`
- 현재 동작 또는 문제: 현재 화면은 `work/screen_template.html`을 `work/sync_frontend.mjs`로 동기화해 실행하며, 백엔드는 샘플 엑셀 또는 로컬 JSON을 읽는다. 기본 조회·집계는 있으나 명세와 차이가 있다.
- 미확인 사항: 브라우저·API 끝단 동작은 이번 조사에서 재검증하지 않음

## 수정 방안

1. 엑셀의 모든 시트와 요구 항목을 추출해 분류한다.
2. 프로젝트 코드·설정·문서를 확인해 항목별 근거를 연결한다.
3. 전체 대조 보고서를 작성하고 미검증 사항을 분리한다.

## 검증

- 실행: Python `openpyxl` 읽기 전용으로 원본 10개 시트(항목명세 105개 필드 포함) 추출, `rg` 및 코드 확인, Python으로 로컬 JSON의 15개 테이블 행 수와 샘플 지표 독립 계산
- 결과: 15개 테이블의 행 수가 명세 예시와 일치. 2026-09-16 12:00 KST 기준 금일 2/6, 기한 도래 45건 중 미완료 4건, 미해소 사건 3건, 설비 고장 1/8대 확인.
- 실행하지 않은 검증: 브라우저 상호작용, API 호출, 빌드·테스트. 조사 요청이며 코드 동작은 정적 근거로 판정함.

## 남은 항목과 제약

- 데이터 전체 행·필드·관계의 전수 무결성 검증은 수행하지 않음.
- 실제 공장 도면 및 기존 제품 화면은 명세에 제공되지 않아 일치 여부를 판단할 수 없음.

## 결과

완료. 명세의 요청사항대응, 데이터구성·관계·항목, 업무시나리오, 기능·화면, 운영요약, 구현참고, 공정·배치도를 현재 실행 코드와 대조하여 전체 보고서를 작성했다. 주요 차이는 서버 검증, 권한·감사, 서버 계산/AI 요약, 좌표 배치, 계획 대비 실적 상세, 과거 시각 재생 UI다.
