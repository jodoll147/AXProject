# 작업 기록: Settings 권한 화면 Figma 설계

## 요청

- Settings 탭에서 세 역할의 권한을 설정할 수 있는 화면을 Figma로 설계한다.
- 역할별 권한 부여는 관리자만 수행하도록 설계하고 결과를 보고한다.

## 현재 상태와 근거

- `docs/엑셀_권한_확인과_3역할_설계안.md`: 세 역할과 서버 인가 제안.
- `work/screen_template.html`: 현재 운영 화면. 역할 선택은 화면 시연이고 실제 인가는 없다.
- Figma 연결을 확인했고 기존 대상 파일이 없어 새 디자인 파일을 만들었다. 검색한 라이브러리에서 관련 디자인 시스템 항목은 발견되지 않았다.

## 수정 방안

1. 현재 화면의 시각 언어와 Figma 파일·디자인 시스템을 확인한다.
2. 관리자용 설정 화면과 권한 없는 사용자 상태를 편집 가능한 Figma 레이어로 설계한다.
3. 결과를 시각·구조 검증하고 링크와 제약을 기록한다.

## 검증

- 실행: Figma 생성 결과의 프레임·노드 ID 확인, Figma 브라우저에서 관리자 및 조회자 화면 각각 시각 확인, 프로젝트 문서 목차 확인.
- 결과: 1440×1180 화면 두 개에 Settings 내비게이션, 세 역할 권한표, 사용자 역할 배정 및 관리자 전용 안내를 배치했다. Figma 작성 결과는 텍스트와 프레임 등 편집 가능한 레이어로 생성됐다.
- 실행하지 않은 검증: 실제 인증·권한 API 및 클릭 동작은 설계 범위라 구현하거나 테스트하지 않았다. Figma MCP Starter 호출 한도로 도구 스크린샷 호출은 실패했으며 브라우저 시각 확인으로 대체했다.

## 남은 항목과 제약

- 역할별 권한 저장과 사용자 역할 변경을 관리자만 수행하도록 서버에서 검증하는 구현이 별도로 필요하다. 표시된 사용자와 ID는 설계용 예시다.

## 결과

완료. Figma에 관리자 설정 화면과 조회자 접근 제한 화면을 설계했다. 실제 앱 기능 구현은 포함하지 않았다.
