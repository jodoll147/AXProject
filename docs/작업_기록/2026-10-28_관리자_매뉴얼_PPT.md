# 작업 기록: 관리자 매뉴얼 PPT

## 요청

- 조선 AX 프로그램의 관리자 매뉴얼을 작성한다.

## 현재 상태와 근거

- 관련 파일/기능: `app/frontend/index.html`, `app/backend/Program.cs`, `docs/로그인_권한_감사.md`, `docs/CSV_폴더업로드_및_중복검증.md`, `docs/2D배치_좌표편집_과거재생_구현.md`.
- 현재 동작 또는 문제: 관리자 화면은 역할별 권한, 사용자, 감사 이력, CSV 적재·초기화, 공정 배치 좌표를 제공한다. 관리자 전용 통합 매뉴얼은 없었다.
- 미확인 사항: 관리자 설정의 계정·감사 화면 캡처는 저장소에서 찾지 못했다.

## 수정 방안

1. 현재 관리자 화면과 서버 권한·저장 동작을 코드 기준으로 확인한다.
2. 제품 구현 캡처가 있는 업로드·좌표 화면은 화면과 함께 절차를 설명하고, 캡처가 없는 계정·감사는 UI 항목과 조작 순서를 정확히 기록한다.
3. 별도 PPT를 신규 작성하고 렌더링·파일 구조를 검증한다. 기존 사용자 매뉴얼과 원본 요구사항은 보존한다.

## 검증

- 실행: 15장 렌더링 및 주요 슬라이드 시각 검토, 프레젠테이션 구조·레이아웃·가져오기 검사, PPTX ZIP 무결성·슬라이드·이미지 수 검사, `git diff --check`.
- 결과: 구조·레이아웃·가져오기 검사는 마지막 파일 링크 단계 전까지 통과했다. 결과 PPTX의 ZIP은 정상이며 15장·제품 이미지 3개를 포함한다. 검토한 슬라이드에서 잘림·겹침을 발견하지 못했고 `git diff --check`가 통과했다.
- 실행하지 않은 검증: PowerPoint 앱 직접 열기와 실제 관리자 계정으로 업무 수행은 실행하지 않았다.

## 남은 항목과 제약

- 계정·감사 화면의 제품 캡처가 없어 해당 장은 현재 UI 코드에 근거한 절차로 작성했다.
- 최종화 도구의 Windows 파일 링크가 권한 오류로 실패해 검사된 초안 PPTX를 결과 경로로 복사하고 ZIP 무결성을 재확인했다.
