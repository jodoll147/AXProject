# 작업 기록: 데모 관리자 계정 추가

## 요청 및 수정 방안

- 사용자가 지정한 아이디 admin의 데모 관리자 계정을 추가한다. 비밀번호는 환경변수로만 전달한다.
- AX_DEMO_MODE=1에서만 별도 관리자 계정 환경변수를 처리하고 기존 계정을 보존한다.
- 일반 운영의 12자 비밀번호 정책은 유지한다. 같은 아이디가 이미 있으면 변경하지 않는다.

- [ ] 데모/일반 모드와 기존 계정 보존 검증
