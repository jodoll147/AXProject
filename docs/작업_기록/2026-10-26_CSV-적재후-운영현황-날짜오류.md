# 작업 기록: CSV 적재 후 운영현황 날짜 오류

## 요청

- CSV 데이터를 적재한 뒤 운영현황이 표시되지 않는 문제를 확인하고 수정한다.

## 현재 상태와 근거

- 로컬 저장소의 15개 테이블에 데이터가 모두 적재되어 있고, 업로드 화면은 준비 완료로 표시한다.
- 브라우저 콘솔에서 `RangeError: Invalid time value`가 `metrics → ymd → iso` 경로로 발생한다.
- `work/screen_template.html`의 `kst`는 모든 시간 문자열에 `:00+09:00`을 덧붙인다. CSV에 이미 `2026-09-16T12:00:00+09:00` 형식으로 들어온 값에는 시간대가 중복된다.

## 수정 방안

1. 시각 문자열에 시간대가 포함되어 있으면 그대로 파싱하고, 기존 샘플처럼 시간대가 없을 때만 `+09:00`을 붙인다.
2. 현재 적재 데이터를 보존하고 운영현황·조회·운영요약 표시를 확인한다.
3. 빌드와 작업 기록을 갱신한다.

## 변경 파일

- `work/screen_template.html`, `app/frontend/index.html` — 이미 시간대가 있는 값은 그대로 파싱하고, 시간대가 없는 샘플 값에만 `+09:00` 적용.
- `docs/데이터베이스.md` — 두 날짜 형식의 화면 해석 방식 기록.

## 검증

- `npm run build` (`app/frontend`) 성공.
- 현재 로컬 데이터의 시간 값 1,088개를 새 규칙으로 확인: 파싱 오류 0건.
- 브라우저 운영현황에 금일 완료 2/6건, 미해소 사건 3건, 고장 설비 1/8대 표시 확인. 조회 12블록과 운영요약도 정상 표시 확인.
- 기존 로컬 데이터 15개 테이블의 적재 행은 변경하지 않음.
