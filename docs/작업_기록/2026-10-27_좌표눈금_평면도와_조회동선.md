# 작업 기록: 좌표 눈금 평면도와 조회 동선 정리

## 요청
- 구역 좌표가 눈에 보이는 모눈 평면도로 배치도 부분을 다시 설계한다.
- 첨부한 미리보기용 바로가기 버튼을 제거하고 기존 조회 탭으로 진입하도록 한다.
- 타임라인 재생의 구현 위치와 사용 경로를 확인한다.

## 현재 상태와 근거
- 독립 시안의 2D 구역은 좌표로 배치되지만 눈금과 좌표 숫자가 없었다.
- 시안 상단에 별도 화면 바로가기와 중복 조회 버튼이 있었다.
- 재생 패널/타이머는 `work/ui_redesign_preview.js`에만 있고 제품 템플릿·프런트엔드에는 없다.

## 수정 방안
1. 좌표 원점·X/Y축·주/보조 눈금과 구역별 좌표 배지를 표시한다.
2. 구역 좌상단을 저장 좌표에 대응시키며 상대 위치와 기존 상태 정보를 유지한다.
3. 별도 바로가기를 제거하고 기존 조회 탭→상세→과거 이력 조회 흐름을 검증한다.
4. 구현/시안/Figma 상태를 구분해 문서와 작업 기록에 남긴다.

## 검증
- 빌더·시안 스크립트 문법 검사 통과.
- 생성한 layoutHTML을 격리 실행하여 샘플 3구역의 위치/배지, 좌표 이동 시 위치 변화, 음수 좌표 범위 확장, 빈 좌표 안내를 확인했다.
- 생성 HTML에서 첨부한 별도 바로가기·중복 조회 버튼 제거 확인.
- 브라우저에서 모눈 숫자 눈금과 6개 구역 좌표 표시 확인. 구역 좌상단은 저장 좌표에 대응함.
- 기존 상단 조회 탭 → 작업(블록) 목록 B008 → 블록 상세 → 과거 이력 조회 경로 확인.
- 최신 시각의 재생 비활성 → 11:30 적용 후 활성 → 재생 중/정지 표시 → 12:00 자동 정지 확인.
- 실제 제품 `work/screen_template.html`, `app/frontend/index.html`은 AS_OF 설정만 있고 재생 컨트롤/타이머는 없음을 코드 검색으로 확인했다. 이번에는 제품 서버의 화면을 다시 검증하지 않았다.
- 실행하지 않은 검증: 전체 제품 통합, 모든 화면 크기, 모든 시간 경계, Figma 레이어 검증.

## 남은 항목과 제약
- 수정 대상은 디자인 시안이다. 실제 제품의 2D 배치/과거 재생 구현은 미적용이다.
- 좌표는 개념값이며 실제 길이 단위가 아니다. 좌표 수정 기능은 추가하지 않았다.
- Figma 반영은 이전에 확인한 Starter MCP 한도로 대기 중이다. 이번에는 재호출하지 않았다.

## 결과
