# 작업 기록: 메인 로그인 진입 추가

## 요청

- 현재 메인 화면 상단에 로그인 버튼과 로그인 화면 진입을 추가한다.

## 현재 상태와 근거

- `work/screen_template.html`이 실행 화면의 원본이다. 상단에 로그인 버튼과 인증 기능이 없다.
- 로그인 화면의 Figma 추가는 호출 한도로 완료하지 못했으며 로컬 설계안이 있다.
- 인증 서버와 계정은 아직 구현되지 않았다.

## 수정 방안

1. 상단에 로그인 진입 버튼을 추가하고 로그인 안내 화면을 제공한다.
2. 실제 인증이 아직 구현되지 않은 상태를 표시해 오인하지 않도록 한다.
3. 실행 화면을 동기화하고 검증 및 문서 기록을 갱신한다.

## 변경 파일

- `work/screen_template.html` — 상단 로그인 버튼과 준비 화면, 화면 경로 추가.
- `app/frontend/index.html` — 템플릿에서 실행 화면 동기화.
- `docs/기능.md` — 로그인 준비 상태 안내.
- `docs/작업_기록/README.md`, `docs/작업_기록/2026-10-27_메인_로그인_진입_추가.md` — 작업 기록.

## 검증

- 실행: `node work/sync_frontend.mjs`, Vite 직접 빌드, 인라인 스크립트 구문 및 로그인 링크·준비 화면 확인. 문서 목차 링크 확인.
- 결과: 화면 동기화와 Vite 빌드 성공, 스크립트 구문 및 로그인 진입 요소 확인. pnpm 빌드는 로컬 저장소 프로젝트 symlink 생성 권한 오류로 실패해 동일 Vite CLI를 직접 실행했다.
- 실행하지 않은 검증: 브라우저 상호작용 및 인증 API 테스트. 백엔드 서버가 실행 중이지 않았고 인증 기능도 미구현이다.

## 남은 항목과 제약

- 실제 인증 기능은 별도 구현이 필요하다.

## 결과

완료. 상단 로그인 버튼에서 인증 준비 화면으로 이동한다. 실제 로그인 기능은 제공하지 않으며 입력과 제출은 비활성화했다.
