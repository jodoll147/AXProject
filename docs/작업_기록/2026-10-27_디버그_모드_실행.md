# 작업 기록: 디버그 모드 실행

## 요청

- 현재 코드를 디버그 모드로 실행한다.

## 현재 상태와 근거

- 백엔드는 ASP.NET Core Debug 구성, 프런트엔드는 Vite 개발 서버다.
- 실제 관리자 계정 상태 파일이 없으므로 최초 로그인에는 사용자가 정한 계정이 필요하다.
- 기본 포트 5173·5182에는 기존 서버가 실행 중이어서 이를 유지하고 5298·5299를 사용한다.

## 수정 방안

1. 기존 프로세스와 포트를 확인해 충돌 없이 개발 서버를 실행한다.
2. 서버와 화면 응답을 확인하고 실제 계정 설정 상태를 기록한다.
3. 작업 기록과 기존 문서 목차를 확인한다.

## 검증

- 실행: `dotnet build --configuration Debug --no-restore`, Debug DLL을 `ASPNETCORE_ENVIRONMENT=Development`로 실행, Vite 개발 서버 실행, health·인증 상태·화면 HTTP 확인.
- 결과: 백엔드 `127.0.0.1:5299` health `ok`, 프런트엔드 `127.0.0.1:5298` HTTP 200. 실제 관리자 초기화 여부 `false`, 초기 데이터 원본 `local-data.json`.
- 실행하지 않은 검증: 최초 관리자 계정이 없어 실제 사용자 계정으로 로그인하지 않았다.

## 남은 항목과 제약

- 관리자 계정이 아직 없다. 사용자가 직접 관리자 아이디·비밀번호를 설정한 뒤 백엔드를 다시 시작해야 로그인할 수 있다. 기존 서버는 변경하지 않았다.

## 결과

완료. 최신 코드를 별도 포트에서 Debug 백엔드와 Vite 개발 서버로 실행했다. 최초 관리자 설정은 남아 있다.
