# 작업 기록: 권한·감사 통합 계획

## 요청

- 업로드 검증 계획에 권한관리와 감사이력을 필수 구현 범위로 포함한다. 사용자의 후속 지시에 따라 서버 운영요약은 계획에서 제외한다.

## 현재 상태와 근거

- 관련 파일: `docs/서버_업로드_검증_구현_계획.md`, `app/backend/Program.cs`, `work/screen_template.html`.
- 역할 선택은 화면 변수이며 서버 인증·인가가 없다. 업로드 이력은 브라우저 세션에만 있고, 운영요약은 브라우저에서 계산한다.
- 미확인 사항: 계정 운영 방식, 역할별 담당 범위, 감사 보존 기간.

## 수정 방안

1. 필수 범위와 의존성을 반영해 통합 우선순위를 갱신한다.
2. 권한과 감사의 API·저장·화면·테스트 범위와 정책 결정을 정리한다.
3. 기존 문서 목차를 확인하고 기록을 갱신한다.

## 검증

- 실행: 기존 계획과 서버 API·화면 역할/이력 코드를 확인하고 문서 목차를 점검했다.
- 결과: 인증·인가, 담당 입력, 영구 감사 및 데이터·감사 일관성, 테스트 범위를 계획에 포함했다. 서버 운영요약은 제외했다.
