# 작업 기록: 계획·실적 비교 화면 공정 배치도 축소 시안

## 요청
- 계획·실적 비교 화면에 기존보다 작은 공정 배치도를 추가한다.

## 현재 상태와 근거
- 조회 비교 시안은 공정 선택 목록과 기간별 비교를 제공한다.
- 기존 메인 배치도는 zones.x/y 기반의 큰 구역 카드다.

## 수정 방안
1. 조회 비교 화면에 작은 2D 구역 카드를 배치한다.
2. 구역 선택을 공정 선택과 연결하고 선택 공정과 단위를 표시한다.
3. 좁은 화면과 샘플 상태 및 선택 동작을 확인하고 기록한다.

## 검증
- `node --check work/ui_compare_preview.js`, 생성 HTML 스크립트 문법 검사 및 생성 성공.
- 브라우저에서 조회 → 계획·실적 비교의 6개 축소 구역 및 상태를 시각 확인.
- 검사 구역 선택 시 검사 공정, 개 단위, WO007-04 표시 확인.
- 시작일 변경 후 용접 구역 선택 시 새 기간 유지, m 단위와 선택 상태 확인.
- 예시 페이지는 최신 스냅샷 상태를 표시한다. 전체 화면 폭, 비정상·누락 좌표, 실제 서버 연동은 검증하지 않았다.

## 남은 항목과 제약
- 독립 시안만 수정했으며 실제 제품의 비교 화면·배치도 기능은 미구현이다.
- 배치도의 상태는 최신 데이터 기준이며 선택 기간의 이력 상태가 아니다.
- Figma 반영은 이전에 확인한 Starter 플랜 MCP 한도로 대기 중이며 이번에 재호출하지 않았다.
