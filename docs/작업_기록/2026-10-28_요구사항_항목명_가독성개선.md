# 작업 기록: 요구사항 대조표 항목명 정리

## 요청
- 요구사항 대조 문서에서 항목 코드 대신 직관적인 항목명을 사용하고 한눈에 볼 수 있게 정리한다.

## 현재 상태와 근거
- 기준 문서에는 R01~R21 및 U01~U05 코드가 표시되어 해당 의미를 다시 찾아야 한다.
- 원본 Excel 및 기존 요구사항의 의미·판정·출처는 변경하지 않는다.

## 수정 방안
1. 원본 대조표와 사용자 결정 표에 항목명을 앞에 배치하고 상태·상세·원본 위치를 유지한다.
2. 잔여 작업 및 알고리즘의 코드 참조를 항목명으로 바꾼다.
3. 표의 항목 수·내용·원본 해시와 문서 목차 링크를 확인한다.

## 검증
- 원본 요구 항목 21개, 사용자 결정·제안 7개 유지 및 기준 문서에 R/U 항목 코드가 남지 않은 것 확인.
- 원본 Excel SHA-256이 기존 기준 해시와 동일함 확인. 원본 요구의 설명·상태·시트/셀은 표 열을 이동해 보존.
- 기준 문서 링크와 프로젝트 문서 목차 링크 확인. git diff --check 공백 오류 없음(줄바꿈 안내만 발생).
- 문서 표시 정리만 수행하여 코드 테스트·빌드는 실행하지 않았다.

## 남은 항목과 제약
- 원본 Excel은 수정하지 않았고 현재 기준 문서의 구현 판정은 2026-10-28 정적 대조 기준이다.
- 기존 미커밋 변경을 보존했으며 커밋·푸시는 수행하지 않았다.
