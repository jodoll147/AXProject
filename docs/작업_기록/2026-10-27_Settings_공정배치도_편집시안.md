# 작업 기록: Settings 공정 배치도 편집 시안

## 요청
- 메인 배치도에서 좌표·눈금 설명을 숨긴다.
- Settings에 공정 배치도 수정 탭을 추가하고 적재된 zones를 모눈 편집 화면에서 수정하는 디자인으로 반영한다.

## 현재 상태와 근거
- 독립 디자인 시안은 메인에서 좌표·눈금·좌표 범례를 표시한다.
- 실제 제품에는 좌표 수정 API나 화면이 없다. 현재 요청은 디자인 시안의 다음 수정이다.
- Figma 작업은 앞서 확인한 Starter MCP 호출 한도로 대기 중이다.

## 수정 방안
1. 메인은 저장된 배치의 운영 상태만 표시한다.
2. Settings에 관리자 편집 시안을 추가한다. 구역 선택·드래그·좌표 입력·격자 맞춤·변경 되돌리기·저장을 체험한다.
3. 편집 초안과 적용된 배치를 분리해 저장 전 메인 변경을 방지하고, 시안 저장 후 메인 반영을 확인한다.
4. 실제 서버 저장/감사 구현과 시안 동작을 구분해 보고한다.

## 검증 결과
- 빌더·시안 스크립트·생성 HTML 문법 검사 및 문서 목차/보고서 상대 링크 확인 통과.
- 브라우저에서 메인 좌표·눈금 숨김과 Settings 공정 배치도 수정 탭 확인.
- Z01 X/Y 입력 (40,60)→(80,100), 저장 전 변경 1건과 비교 표시 확인.
- 메인 왕복 후 초안 유지와 메인 구역의 기존 위치 유지 확인.
- 되돌리기 후 (40,60) 및 저장 비활성 확인.
- 드래그로 (80,100) 이동 및 20단위 격자 맞춤 확인.
- 시안 저장 후 메인 위치가 left:64/top:84에서 left:104/top:124로 변경됨을 DOM으로 확인. 메인 좌표 배지/눈금 0개 확인.
- 새로고침 후 샘플 좌표 초기화, Z03 선택 패널과 편집 화면 배치를 시각 검증.
- 실행하지 않은 검증: 실제 서버 저장·인가·감사, 모든 기기 크기, 좌표 겹침/범위/동시 편집 정책, Figma 레이어.

## 남은 항목과 제약
- 디자인 시안 안에서만 편집·저장된다. 원본 CSV/JSON/엑셀이나 실제 제품은 변경하지 않았다.
- 관리자 전용 서버 수정 API와 실제 감사이력 연결은 제품 적용 단계의 미구현 항목이다.
- 기존 Settings 역할·계정·감사 탭은 디자인 범위 표시용으로 비활성이며 실제 제품 기능이 제거된 것은 아니다.
- Figma는 기존 MCP 한도 차단 상태로 이번 작업에서 재호출하지 않았다.

## 최종 상태
완료. 메인 읽기 전용 표시와 Settings 모눈 편집 화면을 분리한 디자인 시안을 작성하고 저장 전후 흐름을 확인했다. 실제 제품 및 Figma 반영은 미완료다.
