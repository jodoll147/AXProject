# 작업 기록: 조회 계획·실적 비교 제품 적용

## 요청
- 축소 공정 배치도에 구역 코드와 공정 코드를 표시한다.
- 검토한 조회 계획·실적 비교 시안대로 실제 제품 작업을 진행한다.

## 현재 상태와 근거
- 현재 제품에는 작업별 상세 비교만 있고 여러 작업의 기간 비교는 시안에만 있다.
- 제품은 `work/screen_template.html`을 `work/sync_frontend.mjs`로 생성한다.
- 기존 디자인 작업물은 미커밋 상태이며 보존한다.

## 수정 방안
1. 시안의 조회 내 계획·실적 비교와 축소 배치도를 제품 공통 템플릿에 적용한다.
2. 구역 Z코드·공정 P코드를 모두 표시하고 공정 선택을 비교 조건과 연결한다.
3. 집계를 분리해 같은 공정·단위, 날짜·미래 계획·실적, 빈값·0을 검증한다.
4. 프런트엔드 생성·빌드와 실제 로그인 화면 동선을 확인하고 문서를 갱신한다.
