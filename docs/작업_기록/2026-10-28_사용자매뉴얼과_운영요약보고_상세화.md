# 작업 기록: 사용자 매뉴얼과 운영요약 보고 상세화

## 요청

- 기존 사용자 매뉴얼 PPT와 운영요약 알고리즘 보고서를 더 자세하게 작성한다.

## 현재 상태와 근거

- 관련 파일/기능: `outputs/조선_AX_프로그램_사용자_매뉴얼_초안_2026-10-28.pptx`, `docs/운영요약_알고리즘_코드_보고_2026-10-28.md`, `app/frontend/index.html`.
- 현재 동작 또는 문제: 기존 PPT는 화면 5개를 포함한 8장 개요이며, 보고서는 주요 규칙을 정리했지만 사용자별 절차와 분기 예시는 더 필요했다.
- 미확인 사항: 운영요약 화면의 별도 제품 캡처는 저장소에 없음을 재확인했다.

## 수정 방안

1. 현재 코드와 제품 화면을 다시 대조해 조작 절차, 확인 결과, 주의사항을 화면별로 확장한다.
2. 기존 보고서에 입력 필드, 상태 분기, 예시 계산, 출력 예시와 예외·제약을 추가한다.
3. 기존 초안은 보존하고 상세판 PPT를 새 이름으로 만든 뒤 렌더링과 내용 검증을 수행한다.

## 검증

- 실행: PPT 16장 렌더링 및 개별 시각 검토, 프레젠테이션 구조·레이아웃·가져오기 검사, 결과 PPTX ZIP 무결성·슬라이드·이미지 수 확인, `git diff --check`.
- 결과: 렌더링에서 잘림·겹침을 발견하지 못했다. 구조·레이아웃·가져오기 검사는 파일 링크 단계 전까지 통과했다. 결과 파일은 ZIP 정상, 16장·이미지 7개이며 `git diff --check`가 통과했다.
- 실행하지 않은 검증: 실제 PowerPoint 앱에서 열기와 CSV를 이용한 운영요약 통합 테스트는 실행하지 않았다.

## 남은 항목과 제약

- 운영요약 제품 화면의 저장된 캡처가 없어 관련 2장은 코드와 기능 문서에 근거한 절차로 작성했다.
- 최종화 도구의 Windows 파일 링크가 권한 오류로 실패해 검사된 초안 파일을 새 결과 경로로 복사하고 ZIP 무결성을 재확인했다.
