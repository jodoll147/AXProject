# 작업 기록: 기존 화면 기반 2D 배치 및 조회 상세 재설계

## 요청
- 기존 디자인을 기반으로 필요한 부분을 추려 새 디자인을 만들고 보고한다.

## 현재 상태와 근거
- 기존 운영현황에는 지표·공정 배치도·주목할 작업이 있다.
- 기존 독립 시안은 메인에 과거 재생과 블록 표를 배치했으나, 이후 대화에서 과거 조회를 조회 상세로 옮기기로 정했다.
- zones.x/y는 존재하지만 좌표 편집 화면은 명세에 없다.

## 수정 방안
1. 기존 제품 화면을 복제한 독립 시안에서 3D 공정 개념도를 좌표 기반 2D로 바꾼다.
2. 메인은 최신 기준을 유지하고 조회의 블록·작업·설비 상세에만 과거 시각 패널을 배치한다.
3. 변경 이유·근거·상태를 문서화하고 주요 화면을 검증한다.

## 남은 항목과 제약
- 사용자가 Figma 작업을 요청하여 세션을 생성했지만, 기존 화면 조회에서 Starter 플랜의 MCP 호출 한도 오류를 받았다. Figma 노드 조회/생성/수정을 진행하지 못했다.
- 준비본은 로컬이며 Figma 반영 및 디자인 최종 확정은 미완료다.
- 실제 제품 코드는 변경하지 않았다. 로컬 미리보기 PID 50464, 포트 5303.
