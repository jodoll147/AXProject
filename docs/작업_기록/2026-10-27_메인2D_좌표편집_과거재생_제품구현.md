# 작업 기록: 메인 2D·좌표 편집·과거 재생 제품 구현

## 요청
- 독립 시안의 메인 2D 전환, 관리자 좌표 편집·저장, 조회 상세 과거 시각 선택·재생을 실제 코드에 구현.

## 현재 상태와 근거
- work/ui_layout_preview.js 및 work/ui_redesign_preview.js에 시안 동작 존재.
- 제품 생성 원본은 work/screen_template.html, 데이터 저장은 app/backend/AppStore.cs.
- 기존 미커밋 변경을 보존하고 구현 범위를 확장한다.

## 수정 방안
1. 메인 좌표 기반 2D와 중복 테두리 제거를 공통 제품 화면에 적용.
2. 관리자 전용 좌표 저장 API, 서버 검증·감사·영속 저장과 편집 화면 연결.
3. 상세에서만 과거 선택·재생을 제공하고 이후 데이터 제외 및 최신 복귀 검증.
4. 빌드·계산/API 테스트·실제 화면 확인, 관련 문서 상태 갱신.

## 검증과 결과
- dotnet build app/backend/AxBackend.csproj -o app/backend/bin/layout-debug --no-restore: 성공, 경고·오류 0.
- npm --prefix app/frontend run build: 성공.
- node --test work/tests/*.test.mjs: 19개 통과. 일반 샌드박스의 로컬 소켓 제한으로 격리 API 테스트가 최초 실행에서 시작 실패했고, 로컬 테스트 서버 실행 권한으로 재실행하여 최종 전체 통과.
- API 테스트는 임시 상태·키 디렉터리를 사용하는 별도 5311 서버에서 수행. 미인증 401, VIEWER/WORKER 403, 중복/미등록/범위 초과 400, 이전 좌표 충돌 409, 요청 전체 거부, 두 구역 일괄 저장, 무관한 작업 데이터 보존, 전후 감사, 프로세스 재시작 후 좌표·감사 지속 확인. 임시 서버·파일 정리.
- 시간 테스트: 모든 관측 종류·스냅샷 상한·관측 없음, KST 입력/초·날짜 오류, 재생 경계, 실적·이벤트·사건 발생/해소 경계, 빈 해소시각, 설비 반개구간·공백·중복 검증. 기존 비교 테스트 12개도 유지.

## 남은 항목과 제약
- 요청한 세 항목은 제품에 구현. Figma 편집 레이어는 이번 코드 구현에서 수정하지 않음.
- 좌표 중첩 자동 회피는 하지 않으며 관리자 입력으로 위치를 조정. 좌표는 개념 좌표이고 원본 CSV/엑셀 덮어쓰기 없음.
- 기존 단일 프로세스 로컬 상태 파일 저장 방식 유지. 운영 DB·다중 서버 쓰기·실시간 다른 브라우저 푸시는 범위 밖.
- 과거 조회는 현재 적재 이력의 시간 필터이며 당시 데이터 버전 복원은 아님. 모든 브라우저 크기·장애 주입·자동 드래그 E2E는 검증하지 않음.
- 기존 미커밋 변경 보존. 커밋·푸시는 수행하지 않음.
