# 작업 기록: 관리자 매뉴얼 화면별 상세화

## 요청

- 기존 관리자 매뉴얼이 개략적이므로 화면별 기능을 더 세세하게 작성한다.

## 현재 상태와 근거

- 관련 파일/기능: `outputs/조선_AX_관리자_매뉴얼_초안_2026-10-28.pptx`, `app/frontend/index.html`, `app/backend/Program.cs`, `docs/로그인_권한_감사.md`, `docs/CSV_폴더업로드_및_중복검증.md`, `docs/2D배치_좌표편집_과거재생_구현.md`.
- 현재 동작 또는 문제: 기존 15장 PPT는 관리자 기능의 조작 개요만 보여주며, 화면의 각 입력 항목·버튼·저장 결과·오류 처리 설명이 부족하다.
- 화면 확인: 별도 상태 파일을 사용한 격리된 샘플 실행에서 권한·사용자·감사·업로드·배치 화면을 촬영했다. 폴더 업로드·담당 입력은 기존 제품 화면 캡처를 사용했다.

## 수정 방안

1. 화면별 코드와 서버 저장·권한 규칙을 대조한다.
2. 권한, 사용자 관리, 감사, 업로드, 초기화·복원, 좌표 편집을 각 컨트롤과 결과 중심으로 상세 매뉴얼에 작성한다.
3. 기존 초안은 보존하고 상세판 PPT를 새 파일로 만들며, 화면 이미지의 출처와 미확인 부분을 구분한다.

- 실행: 격리된 상태 파일로 로컬 제품 화면을 띄워 관리자 메뉴 5곳을 캡처했다. PPT 27장을 PNG로 렌더링하고 주요 화면·절차 슬라이드의 글자 배치와 잘림을 눈으로 확인했다.
- 실행: 프레젠테이션 패키지 무결성·배치·Artifact Tool 재가져오기 검증을 통과했다. 최종 PPT의 ZIP 구성 검사에서 손상 멤버 0개, 슬라이드 27개, 내장 화면 이미지 7개를 확인했다. `git diff --check`를 실행했다.
- 결과: 최종 파일을 `outputs`에 저장했다. 발표용 PPT와 상세 참조용 Markdown 문서가 같은 화면 기능을 설명한다.
- 실행하지 않은 검증: 실제 운영 계정·데이터에 대한 권한 변경, CSV 적재, 초기화·복원은 실행하지 않았다.
