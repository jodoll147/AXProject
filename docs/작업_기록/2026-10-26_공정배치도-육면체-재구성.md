# 작업 기록: 공정 배치도 육면체 재구성

## 요청

- 기존 얕은 입체 카드 대신 첨부 참고 이미지처럼 면이 분명한 육면체 형태로 공정 6개를 표시한다.
- 공정 사이 간격을 넓히고 연결 화살표를 제거한다.

## 현재 상태와 근거

- 관련 파일/기능: `work/screen_template.html`의 `.lay`, `.zbox`, `layoutHTML`, `zoneBox`; `work/sync_frontend.mjs`; `app/frontend/index.html`
- 현재 동작 또는 문제: 카드 기울기와 그림자만 있어 육면체의 앞면·옆면·아랫면이 구분되지 않는다. SVG 화살표가 6개 카드를 연결한다.
- 미확인 사항: 좁은 화면의 실제 시각 검증은 이번 브라우저 세션에서 하지 못했다.

## 수정 방안

1. 배치도를 여백이 있는 3×2 그리드로 바꾸고 SVG 연결 화살표를 제거한다.
2. 각 공정을 SVG 다각형 3개로 만든 입체 블록으로 표현하고, 면별 명도 차이와 상태색을 준다. 공정 아이콘과 텍스트는 읽기 쉬운 면에 배치한다.
3. 운영현황과 블록 상세에서 기존 상태·링크를 유지하고 빌드·화면을 검증한다.
