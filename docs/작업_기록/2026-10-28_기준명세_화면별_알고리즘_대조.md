## 요청

- 요구사항별 현재 구현·부분 구현·미구현을 확인하고 화면별 구현 및 알고리즘을 한 문서로 정리한다.

## 현재 상태와 근거
- 원본은 01_조선_데이터참고명세서.xlsx이며 과거 대조 문서의 조사 시점이 달라 현재 구현과 차이가 있다.
- 실제 실행 원본은 work/screen_template.html, 백엔드는 app/backend/Program.cs 및 AppStore.cs다.
- 원본 Excel은 외부 경로에 있으며 Git 추적 대상이 아니다. 원본 내용을 편집하지 않는다.

## 수정 방안
1. 원본을 읽기 전용 기준으로 식별하고 파일 해시·출처와 변경관리 원칙을 기록한다.
2. 원본 시트·셀과 실제 코드를 연결해 상태·누락·범위 제외 및 사용자 추가 요구를 구분한다.
3. 화면별 기능과 계산 알고리즘, 입력·출력·경계·제약을 기록하고 기존 문서 목차에 기준 문서를 연결한다.
4. 출처·링크·원본 파일 불변 여부를 검증하고 작업 기록을 마무리한다.

## 검증
- 사용자 제공 Excel과 프로젝트 로컬 Excel의 SHA-256을 작업 전후 비교: 둘 다 BE8C9CB69E981835813585FBF52E768D2435C38B75D7E242CF2BD76D6D14271D, 변경 없음.
- 원본 관련 시트·셀과 화면/서버 구현을 읽기 전용으로 대조. 문서의 로컬 Markdown 링크와 프로젝트 문서 목차 링크 모두 존재 확인.
- git diff --check: 공백 오류 없음; Windows 줄바꿈 안내만 발생.
- 기능 코드 변경이 없어 테스트·빌드 재실행하지 않음. 과거 19개 테스트 결과는 기존 작업 기록에서 인용했으며 이번에 재검증하지 않음.

## 남은 항목과 제약
- 원본 파일은 Git 제외 상태이며 운영체제 파일 속성/권한은 변경하지 않았다. AGENTS.md와 기준 문서의 보존 지침 및 해시를 통해 관리한다.
- 전체 원본 데이터 행·필드의 동작과 실제 운영환경/모든 사용자 입력 조합은 이번에 전수 시험하지 않았다. 고정 샘플 시각과 최신 스냅샷 방식, 선후관계 정책, 계획 존재 완전성과 NULL 표현은 문서에 차이·확인 사항으로 표시했다.
- 서버 운영요약은 원본 요구에서 삭제하지 않고 사용자 결정에 따라 범위 제외로 표시했다.
- 기존 로컬 디자인 HTML은 그대로 보존. 커밋·푸시는 요청되지 않아 수행하지 않았다.
