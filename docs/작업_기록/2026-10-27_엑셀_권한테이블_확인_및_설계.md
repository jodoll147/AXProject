# 작업 기록: 엑셀 권한 테이블 확인 및 설계

## 요청

- 목업데이터와 데이터참고명세서에 관리자 권한 관련 테이블이 있는지 확인한다.
- 없는 경우 세 가지 역할을 부여할 수 있는 설계안을 보고한다.

## 현재 상태와 근거

- 관련 자료: 사용자가 지정한 두 엑셀 파일 및 기존 서버 권한·감사 계획.
- 현재 동작: 화면의 역할 선택은 서버 인증·인가가 아니다.
- 확인 결과: 목업의 17개 시트와 참고명세의 10개 시트에서 계정·권한 테이블은 찾지 못했다. 참고명세 `구현참고!B10`에는 역할 제안, `B11`에는 실제 사용자 계정 미포함 안내가 있다.

## 수정 방안

1. 두 파일의 시트, 헤더, 항목명세 및 권한 관련 내용을 확인한다.
2. 계정·역할·담당 범위 및 서버 인가에 대한 세 역할 설계안을 정리한다.
3. 문서 링크와 조사 결과, 미확인 사항을 기록한다.

## 검증

- 실행: 번들 Python과 openpyxl로 두 엑셀 전체 시트의 이름·첫 행·권한 관련 셀을 읽기 전용 조사하고, 작업조·사건 담당조의 값과 현재 코드 확인.
- 결과: 목업 17개 시트 중 업무 데이터는 15개이며 권한 테이블이 없다. 명세 10개 시트에는 3역할 제안만 있다. 작업조 ID와 사건 담당조 명칭의 값 형식이 다르다.
- 실행하지 않은 검증: 실제 인증·인가 구현, 빌드, API 동작 검증. 이번 작업은 조사와 설계다.

## 남은 항목과 제약

- 사용자 인증 방식, 담당자 배정·조회 범위, 감사 보존기간과 저장 방식은 협의가 필요하다.
