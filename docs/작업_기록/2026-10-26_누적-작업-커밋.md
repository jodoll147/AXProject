## 검증

- 실행: `dotnet build app/backend/AxBackend.csproj --no-restore`, `npm run build` (`app/frontend`), `git diff --check`, `docs/프로젝트_기능_설명.md` 목차 링크 확인
- 결과: 백엔드와 프런트엔드 빌드 성공, Git 공백 오류 없음, 목차 링크 대상 존재 확인. 스테이징한 49개 파일을 검토하고 `git diff --cached --check` 통과.
- 실행하지 않은 검증: 별도 통합 테스트는 실행하지 않음. `pnpm --dir app/frontend build`는 샌드박스 밖 pnpm 저장소 심볼릭 링크 권한 오류로 중단되어 동일한 빌드를 `npm run build`로 확인함.
