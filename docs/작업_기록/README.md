# 프로젝트 작업 기록

이 폴더에는 프로젝트 작업마다 날짜별 Markdown 기록을 보관합니다. 작성 형식과 필수 항목은 [수정 작업 템플릿](../수정_작업_템플릿.md)을 따릅니다.

## 기록 규칙

- 파일명 형식: `YYYY-MM-DD_<작업명>.md` (Asia/Seoul 기준)
- 작업 시작 시 요청, 현재 상태, 수정 방안, 작업 목록을 작성합니다.
- 작업 종료 시 변경 파일, 검증 명령과 결과, 남은 항목, 완료 상태를 기록합니다.
- 기존 기록은 덮어쓰지 않습니다.
