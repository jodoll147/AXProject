# 작업 기록: 데이터 초기화와 실제 업로드

## 요청

- 현재 표시되는 샘플 데이터를 초기화하고 CSV 파일을 실제로 적재해 시험할 수 있게 한다.
- 추가 피드백: 데이터가 없을 때 업로드 전용 오류 화면 대신 모든 현황을 0/0 또는 미작업으로 표시한다.

## 현재 상태와 근거

- `app/backend/Program.cs`는 샘플 엑셀 파일을 읽기 전용으로 제공한다.
- `work/screen_template.html`의 업로드 화면은 CSV 검증 결과만 보여주고 데이터를 반영하지 않는다. 현재 세션 업로드 이력은 0건이다.
- 모든 데이터를 비운 후에도 운영현황은 0/0과 미작업으로 표시해야 한다. 초기 업로드 전용 화면은 사용자 피드백에 따라 철회했다.

## 수정 방안

1. 샘플 엑셀은 보존하고, 별도 로컬 데이터 저장소와 초기화·CSV 적재 API를 만든다.
2. 초기화 후에도 운영현황·조회·운영요약을 열고, 데이터가 없으면 0/0·미작업을 표시한다. CSV는 테이블별로 순서대로 적재한다.
3. 기존 업로드 화면도 검증 통과 파일을 실제 저장소에 반영하고 화면을 갱신한다.
4. 데이터 준비 상태, 복구 방법과 제한을 문서화한다.

## 남은 항목과 제약

- CSV는 테이블별로 올려야 하며, 참조 대상 테이블을 먼저 적재해야 한다. 필요한 기준 테이블과 블록별 공정 작업지시가 준비될 때까지 현황은 빈 데이터 표시를 유지한다.
- 운영 DB와 사용자 인증은 연결하지 않은 로컬 시연이다.

## 결과

완료. 현재 로컬 데이터는 모두 비어 있으며 샘플 엑셀 원본은 보존된다. 업로드 화면에서 CSV를 올리면 검증 후 로컬 JSON에 저장된다.
