- **구현**: 현재 실행 코드에서 관련 기능을 확인했다. 해당 항목의 모든 데이터·운영 환경 검증을 뜻하지 않는다.

- **미구현**: 확인한 실행 경로에 기능이 없다.
- **미검증**: 코드만으로 판정할 수 없거나 시험하지 않은 부분이다. 미구현과 구분한다.

## 5. 현재 코드의 주요 계산 알고리즘

`t`는 조회 기준시각, 최신 화면은 `AS_OF`, 과거 상세는 선택시각이다. 날짜 귀속은 KST이다.

| 계산 | 입력 및 현재 알고리즘 | 경계·주의 | 코드 |
| --- | --- | --- | --- |
| 최신/관측 범위 | 유효 스냅샷 중 최대 `as_of`를 상한으로 사용. 없으면 실적·이력·사건·설비구간·검사·재작업의 최신 관측을 사용. 하한은 상한 이하 관측 중 최솟값 | 관측이 전혀 없으면 과거 패널은 자료 없음. 샘플 고정 시각과의 차이는 시간 형식과 기준시각 항목 참고 | `history_state.js` `observationBounds` |
| 작업 상태 | `event_at ≤ t`의 마지막 작업 이벤트를 상태로 매핑. 이벤트가 없으면 PLANNED | START/RESUME/REWORK_DONE→IN_PROGRESS, PAUSE/QUALITY_HOLD→BLOCKED, COMPLETE→COMPLETED | `screen_template.html` `woAt` |
| 작업 인정수량·진척 | 종료시각 `period_end_at ≤ t`인 해당 작업의 `accepted_qty_delta` 합계; 진척 표시 = `min(1, 합계 / work_orders.planned_qty)` | 작업 진척은 표시상 100% 상한. 기간 비교의 달성률에는 상한을 두지 않음. `woAt`은 단위 검증이 정상적으로 적용된 적재 데이터를 전제 | `woAt`, `period_comparison.js` |
