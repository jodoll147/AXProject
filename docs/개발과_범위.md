# 개발·실행 및 범위

## 1. 필수 환경

- .NET SDK 10
- Node.js
- pnpm
- 기존 정적 화면 재생성 시 Python

## 2. Vite + C# 실행

저장소 루트에서 백엔드를 실행합니다.

```powershell
dotnet restore app/backend/AxBackend.csproj
dotnet run --project app/backend/AxBackend.csproj --urls http://127.0.0.1:5182
```

별도 터미널에서 프론트엔드를 실행합니다.

```powershell
cd app/frontend
pnpm install
pnpm dev --host 127.0.0.1
```

`http://127.0.0.1:5173/`에 접속합니다. API 직접 점검은 `http://127.0.0.1:5182/api/health`, `http://127.0.0.1:5182/api/data`를 사용할 수 있습니다.

## 3. 빌드 및 정적 화면

프론트엔드 빌드:

```powershell
cd app/frontend
pnpm build
```

기존 HTML 화면 생성(저장소 루트):

```powershell
python work/build_screen.py
```

결과 파일은 `outputs/조선_AX_이력탐색_화면.html`입니다. `work/screen_template.html`은 생성용 템플릿이고, `work/screen.js`는 기존 화면 관련 스크립트입니다.

## 4. 저장소 디렉터리

| 경로 | 내용 |
| --- | --- |
| `app/frontend` | Vite 웹 화면. 현재 진입점은 생성된 `index.html` |
| `app/backend` | ASP.NET Core API 및 엑셀 로더 |
| `엑셀 파일` | 로컬에서 별도로 준비하는 샘플 데이터, 데이터 참고 명세, 목업 데이터 (Git 제외) |
| `work` | 기존 HTML 화면 템플릿과 생성 도구 |
| `outputs` | 화면 샘플 이미지와 생성된 HTML |
| `docs` | 이 프로젝트 문서 묶음 |

## 5. 구현된 범위

- 운영현황의 핵심 지표, 공정 배치도, 주목 작업. 데이터가 없으면 0/0·미작업 표시
- 작업(블록)·설비·사건·생산 지연 조회와 검색/필터
- 블록·작업·설비 상세
- 규칙 기반 운영요약 편집 및 복사
- 기존 HTML 화면 및 생성 스크립트

## 6. 미구현 또는 제한된 범위

- 운영 DB, MES, PLC, 실시간 설비 텔레메트리 연동 없음
- 엑셀 파일 직접 업로드/수정 없음. CSV 적재는 로컬 JSON 파일에 저장되며 운영 DB는 연결되지 않음
- `app/frontend/src/`의 이전 React 구현은 현재 진입 화면에서 사용하지 않음
- 자동 새로고침/실시간 푸시, 사용자 계정/권한, 배포 설정은 현재 제공하지 않음
- AI 요약은 비활성 상태이며 외부 API, 모델, 키가 연결되지 않음
- 현재 제공 데이터는 합성 샘플이며 운영 의사결정의 실제 데이터로 간주할 수 없음

## 7. 주요 코드 경로

- `app/backend/Program.cs`: 파일 경로, 시트 로더, 캐시, API
- `work/screen_template.html`: 현재 화면·모델 집계·조회·요약·CSV 적재
- `work/sync_frontend.mjs`: 템플릿을 `app/frontend/index.html`로 동기화
- `app/frontend/vite.config.js`: Vite 서버와 API 프록시
- `app/frontend/package.json`: 개발·빌드·린트 스크립트와 의존성
