## 부분 구현·미구현 및 확인할 작업

| 우선순위 | 항목 | 상태 | 다음 작업 |
| --- | --- | --- | --- |
| 1 | 업무 관계·품질·상태 검증 | 부분 구현 / 정책 대기 | 선행 순환·동일 블록·완료 조건, 검사·재작업 관계와 상태 전이·설비 구간 중복 기준 협의 후 서버 검증 |
| 2 | 다중 테이블 일괄 적재 | 미구현 | 참조 순서 자동 처리와 여러 파일 전체 일괄 성공/실패 설계 |
| 3 | 공정 표준시간 | 데이터 적재만 구현 | standard_hours 표시·계획시간 비교의 계산과 평가 기준 결정 후 적용 |
| 4 | 감사 운영 정책 | 일부 구현 | 실패/거부 기록 여부, 보존기간·백업·복구 절차 정의 |
| 5 | 운영 저장·보안·복구 | 일부 구현 / 미검증 | 운영 DB 및 다중 서버 필요성 판단, TLS·인증키 보호·동시 저장·장애 주입·복구 검증 |
| 6 | 공란 저장 표현 | 부분 구현 | 공란과 숫자 0은 구분하나 공란은 필드 생략; 명시적 null 통일 여부 결정 |
| 7 | 실제 자료·반응형 수용 검증 | 미검증 | 실제 데이터, 긴 이름, 해상도별 편집·조회, 드래그 E2E 및 사용자 검수 |
| 별도 | Figma 동기화 | 미반영 | 로컬 제품 코드와 Figma 편집 레이어 동기화 여부 검토. 이전 MCP 한도 문제 확인 |
