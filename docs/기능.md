# 기능 명세

운영 화면을 사용하려면 로그인해야 합니다. Settings에서 관리자는 역할별 권한과 사용자·작업 배정을 관리하고 감사이력을 조회합니다. 작업 입력 권한을 가진 사용자는 배정된 작업의 실적·사건을 입력하고 수정할 수 있습니다. 최초 관리자 생성과 제한 사항은 [로그인·권한·감사](로그인_권한_감사.md)를 참고하세요.

## 1. 운영현황

홈 화면은 전체 호선을 기준으로 네 가지 지표를 제공합니다.

1. **금일 계획 중 완료:** 기준일에 계획 시작된 작업 수 중 상태가 완료인 건수.
2. **기한 도래 미완료:** 계획 종료 시각이 기준시각에 도달했거나 지난 작업 중 완료 상태가 아닌 건수.
3. **미해소 사건:** 기준시각까지 발생한 사건 가운데 해소 시각이 없거나 기준시각 이후인 건수. 설비·자재·품질 유형별 수도 표시합니다.
4. **설비 상태:** 최신 스냅샷에서 고장인 설비 수 / 전체 설비 수. 가동·대기·점검 건수도 표시합니다.

공정 배치도에는 `processes.sequence_no` 순서의 6개 공정이 나타납니다. 사건이 있는 공정은 사건 유형 색상으로, 진행 중인 공정은 작업 중 스타일로 표시합니다. 공정 클릭은 해당 공정 이름을 검색어로 넣고 작업 조회로 이동합니다.

주목할 작업은 미해소 사건과 기한 지연 작업을 작업지시 기준으로 합쳐 중복을 제거합니다. 선택하면 작업 상세를 엽니다.

## 2. 통합 조회

공통 조건은 호선명 정규식, 날짜 범위, 검색어입니다. 설비 조회는 호선 공통이므로 호선 조건을 적용하지 않습니다. `오늘`은 기준일 하루, `전체 기간`은 날짜 조건 해제를 적용합니다. 일반 검색어는 각 목록에 관련된 식별자와 명칭/내용에서 부분 일치합니다. 호선 정규식의 입력 규칙과 필터 순서는 [호선명 정규식 검색](호선명_정규식_검색.md)에 정리했습니다.

### 작업(블록)

- 호선별로 블록을 그룹화합니다.
- 블록의 작업지시를 공정 순서로 표시하고 공정 스트립, 현재/다음 공정, 완료 공정 수, 문제, 목표 이송 시각을 보여줍니다.
- 날짜 범위는 작업 계획 시작일에 적용됩니다.
- 블록·블록명·호선명 검색은 해당 블록에 속한 작업들을 표시하며, 개별 작업 검색은 일치 공정을 강조합니다.
- 블록 행 선택 시 블록 상세를 엽니다.

### 설비

- 설비의 최신 스냅샷 상태, 연결 작업, 공정, 관련 사건을 표시합니다.
- 날짜 범위 내 `equipment_intervals`를 겹치는 시간만큼 잘라 가동·고장·점검 시간을 합산합니다. 비가동(OFFSHIFT)은 점유율 분모에서 제외합니다.
- 가동 점유율은 가동 시간 ÷ 비비가동 상태 구간 합계입니다.
- 설비 행 선택 시 설비 상세를 엽니다.

### 사건

- 설비 고장(EQUIPMENT), 자재 대기(MATERIAL), 품질 보류(QUALITY)를 표시합니다.
- 기준시각 이전 발생 사건을 대상으로 하며 호선, 발생 날짜, 사건/작업/블록/설비 번호, 내용, 담당 팀으로 검색할 수 있습니다.
- 미해소 건과 최근 발생 건이 우선 정렬됩니다.
- 사건 행 선택 시 연결 작업 상세를 엽니다.

### 생산 지연

- 계획 종료 시각이 기준시각에 도달한 작업 중 미완료인 건과, 계획 종료 뒤 완료된 건을 표시합니다.
- 완료 지연은 실제 완료 이벤트 시각, 미완료는 현재 기준시각까지의 경과로 지연을 표현합니다.
- 사건이 없고 예상 완료시각이 있는 미완료 작업은 예상 시각을 표시합니다.
- 작업 행 선택 시 작업 상세를 엽니다.

## 3. 상세 화면

### 블록 상세

- 호선과 목표 이송 시각, 공정 완료 수, 현재 공정, 미해소 사건 수를 요약합니다.
- 블록의 작업지시를 공정 순서로 나열하고 작업 상세로 연결합니다.

### 작업 상세

- 계획 수량, 인정 수량, 진척률, 계획 시작/종료, 예상 완료 시각을 보여줍니다.
- 기준계획 번호·버전·계획일·계획량과 작업별 일별 실적·차이·달성률을 표시합니다. 실적은 한국시간 종료일에 귀속하며 기준시각 이후 실적과 미래 계획 비교를 제외합니다. 당일은 기준시각까지의 값이고 서로 다른 단위는 합산하지 않습니다.
- 기간별 실적 기록에서 기준시각까지 확정된 모든 증분의 집계 시작/종료, 신규/누적 인정수량과 출처를 확인합니다. 계획이 없거나 계획량이 0이면 달성률은 표시하지 않습니다.
- 연결된 모든 사건과 조치 기록, 기준시각까지의 작업 이벤트 이력을 표시합니다.
- 연결 설비를 선택해 설비 상세로 이동합니다.

### 설비 상세

- 최신 스냅샷 상태, 점유 작업, 기준시각을 표시합니다.
- 기준시각 전에 시작된 설비 상태 구간 중 최근 최대 15개를 표시합니다.
- 스냅샷에 연결 작업이 있으면 작업 상세로 이동합니다.

## 4. 규칙 기반 운영요약

- 기준시각과 금일 계획/완료, 기한 도래/미완료, 미해소 사건 수를 계산합니다.
- 미해소 사건별로 작업 진척과 유형별 사실을 구성합니다.
- 품질 사건은 기준시각 이전 검사/보수 기록을 참조해 검사 불합격 수와 인정 수량을 기록합니다.
- 기준일에 해소된 사건은 해소 시각, 완료 여부 또는 현재 진척/예상 완료를 정리합니다.
- 필요한 복구 예상시각, 자재 공급시각, 재검사 판정 등은 확인 요청으로 표시합니다.
- 사용자는 텍스트를 고치고 복사할 수 있습니다. 편집 내용은 브라우저 세션 메모리에서 유지되고 서버/엑셀에 저장되지 않습니다.
- AI 요약 API는 비활성 응답을 반환하며 화면의 AI 결과 영역도 비어 있습니다.

## 5. 시간과 데이터 기준

앱은 엑셀의 `equipment_snapshot.as_of` 가운데 가장 늦은 값을 공통 기준시각으로 사용합니다. 이력·실적·사건을 그 시각까지 잘라 계산하므로, 실제 현재 시각이나 실시간 설비 상태를 뜻하지 않습니다. 시간 문자열은 `+09:00` 기준으로 해석됩니다.

## 조회 → 계획·실적 비교 (2026-10-27 구현)

- 공정·시작일·종료일로 같은 공정과 단위의 여러 작업을 집계합니다. 단위는 공정에 따라 결정됩니다.
- 기간 합계·차이·달성률, 일별 비교, 작업별 내역과 기존 상세 이동을 제공합니다. 필터는 URL에 유지됩니다.
- 축소 배치도는 zones.x/y의 상대 위치를 사용합니다. 구역·공정 코드(Z03 · P03), 이름, 최신 상태를 표시하며 구역 선택 시 입력 기간을 유지합니다.
- 계획은 계획일, 실적은 한국시간 집계 종료일 기준입니다. 기준일 당일 전체 계획과 기준시각까지 실적을 비교합니다. 미래 계획은 표에는 표시하되 합계·달성률에서 제외합니다. 실적 미기록과 기록된 0을 구분합니다.
- 배치도의 상태는 최신 데이터 기준입니다. 메인 2D·관리자 좌표 저장·상세 과거 재생도 실제 제품에 구현했습니다. [구현 범위와 사용 경로](2D배치_좌표편집_과거재생_구현.md)를 참고하세요.
