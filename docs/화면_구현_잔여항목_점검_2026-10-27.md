# 화면 수정 잔여 항목 점검 — 2026-10-27

범위: 데이터 검증·서버 API·운영 정책 같은 기능 구현은 제외하고, **실제 제품 화면에 추가하거나 수정해야 하는 부분**만 정리한다. 기준은 데이터참고명세서의 `기능·화면`, `구현참고`, `공정·배치도`, 현재 `work/screen_template.html`, 최신 독립 디자인 시안과 이후 사용자 요청이다. 과거 작성한 대조 보고서는 당시 상태이므로 이후 구현 내용을 이 문서에서 다시 구분한다.

## 요청 화면의 제품 반영 상태

| 화면 | 현재 구현 |
| --- | --- |
| 메인 공정 배치도 | zones.x/y 기반 2D, Z/P 코드, 외부·내부 중복 테두리 제거. 좌표·눈금은 메인에서 숨김 |
| Settings 공정 배치도 수정 | 관리자 모눈 편집, 드래그·키보드·직접 입력, 변경 내역·되돌리기·서버 저장·감사·충돌 검사 |
| 조회 상세 | 블록·작업·설비의 KST 시각 선택·시간축·재생/정지·최신 복귀 |
| 조회 계획·실적 비교 | 같은 공정·단위의 기간·일별·작업별 비교, 축소 배치도와 구역/공정 코드 |

위 네 항목 모두 실제 제품에 구현했다. [현재 구현 범위와 제약](2D배치_좌표편집_과거재생_구현.md)을 기준으로 한다. Figma 편집 파일 반영과 모든 환경의 화면 검증은 별도다.

## 명세와 화면 배치를 추가 확인할 항목

| 항목 | 확인된 현재 화면 | 판단할 사항 |
| --- | --- | --- |
| 메인 필터 배치 | 명세 `기능·화면` C8은 운영현황에 필터를 예시한다. 실제 메인은 전체 호선 기준이며, 조회 탭에는 호선명·검색·날짜 필드, 공정 배치도에는 공정별 조회 링크가 있다. | 사용자와의 대화에 따라 메인 직접 필터는 추가하지 않고 기존 조회 탭과 공정 링크를 사용한다. |
| 작은 화면과 긴 데이터 | 메인/조회/상세에 반응형·스크롤 스타일은 있으나 모든 크기와 긴 실제 자료를 확인하지 않았다. | 실제 브라우저에서 글자 잘림·테이블·2D 지도와 편집 패널을 확인하고 필요한 곳만 수정한다. 현재 문제로 단정하지 않는다. |

## 이미 있는 화면

| 화면 | 현재 구현 |
| --- | --- |
| 로그인 진입·로그인 | 메인 헤더 진입과 로그인 폼 |
| 운영현황 기본 | 금일 계획/완료, 기한 도래 미완료, 미해소, 설비 상태, 주목할 작업 |
| 통합 조회 | 호선명 정규식·날짜·일반 검색과 작업·설비·사건·지연 목록 |
| 블록·작업·설비 상세 | 작업 흐름, 시간축, 설비 구간, 사건·이력과 계획/실적 상세 |
| Settings | 관리자 역할별 권한, 사용자·담당 작업, 감사이력 |
| 담당 실적·사건 | 입력 종류·기존 기록 선택과 등록/수정 폼. 라벨/입력 여백 조정 반영 |
| 데이터 업로드 | CSV 선택·미리보기·셀 수정·검증 오류 표시 및 적재 |

서버 운영요약·AI는 사용자가 범위에서 제외했다. 좌표를 메인에 숫자로 표시하거나 임의의 ‘주요 사건’ 목록을 메인에 추가하는 방안도 최신 결정이 아니다. 실제 공장 도면은 제공되지 않아 배치도는 교육용 개념도다.

## 이전 시안 점검 이력 (제품 적용 전)

- 메인 2D **시안**에서 외부 패널과 내부 지도에 적용된 테두리·배경을 제거하고 6개 구역 카드의 테두리는 유지했다. Settings의 모눈 편집 영역은 유지한다.
- 브라우저 계산 스타일 확인: 메인 외부/내부 테두리 각 `0px`, 구역 카드 기본 `1px`·왼쪽 `4px`, 구역 6개. Settings 편집 지도 테두리 `1px`, 격자 1개, 구역 6개.
- 실제 제품 화면 전체의 재실행·모든 브라우저 크기와 Figma 편집 레이어는 이번에 검증하지 않았다. Figma 반영은 이전에 확인한 Starter MCP 호출 한도로 대기 중이며 이번 점검에서 재호출하지 않았다.
