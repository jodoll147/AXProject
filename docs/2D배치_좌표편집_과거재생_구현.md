# 2D 배치·좌표 편집·과거 재생 — 제품 구현

2026-10-27 실제 제품 코드에 반영했다. 기존 독립 시안 및 이전 계획 문서의 미구현 표기는 이 문서로 대체한다.

## 화면과 사용 경로

| 화면 | 구현 |
| --- | --- |
| 운영현황 | `zones.x/y` 좌표 기반 2D. 구역 Z코드·공정 P코드·공정명·블록·상태·설비 표시. 외부 패널·안쪽 지도 테두리 제거, 구역 카드 테두리 유지. 메인에는 좌표·모눈·재생 표시 없음 |
| Settings → 공정 배치도 수정 | 관리자만 사용. 모눈·눈금, 선택·드래그·방향키, X/Y 직접 입력, 20단위 격자 맞춤, 변경 내역·되돌리기·서버 배치 다시 불러오기·저장 |
| Settings → 감사이력 | `layout:update`, 대상 `zones`, 수행자·시각·구역별 변경 전후 좌표 |
| 조회 → 블록·작업·설비 상세 → 과거 이력 조회 | KST 날짜·초 단위 시각 적용, 선택일 시간축, ±15분, 1초마다 5/15/30분 재생·일시정지·최신 복귀 |

좌표는 교육용 개념 좌표다. 원본 CSV/엑셀 파일을 덮어쓰지 않고 적재된 서버 데이터만 수정한다. 관리자가 의도적으로 겹쳐 배치할 수 있으며 자동 충돌 회피나 실제 도면 보정은 하지 않는다. 직접 입력으로 겹침을 해소할 수 있다. 좌표를 모두 크게 이동하면 스크롤이 커질 수 있다.

## 서버 저장 계약

`POST /api/admin/layout` — 기존 인증·관리자 인가 및 `X-Requested-With: AXProject` 검사를 사용한다.

```json
{"zones":[{"zoneId":"Z01","x":60,"y":60,"previousX":40,"previousY":60}]}
```

- 기존 구역의 좌표만 수정한다. 구역명·공정 관계 등 다른 필드는 변경하지 않는다.
- 변경 목록 필수, 구역 중복·미등록 구역 거부. 좌표와 이전 값은 -10000~10000 사이의 유한한 숫자다.
- 서버 좌표와 `previousX/Y`가 다르면 전체 요청을 409로 거부한다. 화면의 `서버 배치 다시 불러오기`는 저장 전 초안을 버리고 서버 배치를 다시 읽는다.
- 데이터와 변경 전후 감사는 기존 AppStore의 단일 파일 교체로 함께 저장한다. 저장 실패 시 캐시·초안에 저장 성공을 표시하지 않는다.
- 저장 후 현재 브라우저의 메인·상세·축소 비교 배치에 반영한다. 다른 브라우저는 새로고침해 최신 배치를 읽는다. 실시간 푸시는 추가하지 않았다.
- 현재 저장 방식은 단일 서버 프로세스용 로컬 상태 파일이다. 운영 DB나 다중 서버 동시 쓰기 지원은 추가하지 않았다.

## 과거 조회 계약

- 현재 적재된 이력에서 조회 시점을 재구성한다. 당시 행 버전이나 과거 계획 변경을 복원하는 기능이 아니다.
- 관측 범위는 작업 이력·실적·사건·설비 구간·검사·재작업·스냅샷으로 계산한다. 계획과 예상 완료는 범위를 늘리지 않는다. 최신 상한은 유효 스냅샷의 최신 시각, 없으면 관측 기록의 최신 시각이다. 관측이 없으면 과거 조회는 자료 없음으로 표시한다.
- 생산실적은 종료시각 이하 증분, 작업 상태는 해당 시각 이하 이벤트, 사건은 발생시각 이하로 제한한다. 해소는 유효한 해소시각 이하일 때만 인정한다.
- 검사·재작업은 검사/시작 시각 이하만 표시한다. 미래 보수 완료 수량·종료·최종 메모, 최신 예상 완료값을 과거 사실로 표시하지 않는다.
- 과거 설비는 `start <= t < end` 구간을 사용한다. 공백·중복 구간은 자료 없음으로 처리하며 최신 스냅샷으로 채우지 않는다. 최신 설비 상세는 스냅샷 시각을 표시한다.
- 선택 시각을 상세 URL의 `asOf`에 저장하고 블록·작업·설비 상세 링크에 전달한다. 수동 적용은 브라우저 이력에 남기고 재생 틱은 현재 이력을 교체한다. 잘못된 URL 시각은 최신으로 복귀하며 안내한다.
- 상세 이동·메인·설정·입력 화면 이동 및 탭 숨김 시 재생을 정지한다. 메인·조회 목록은 항상 최신 기준이다. 상세 선택값은 세션 메모리에 유지한다.
