## 한눈에 보기

조선 블록의 작업지시, 생산 실적, 설비 상태와 사건을 모니터링하는 웹 샘플입니다. Vite 화면과 ASP.NET Core API가 별도 폴더에 있습니다. API는 처음에 샘플 엑셀을 읽고 초기화 후에는 로컬 JSON에 CSV를 적재합니다. CSV는 표에서 셀별 검증 결과를 확인·수정하고 업로드 버튼을 눌러 적재합니다. 데이터가 없으면 현황은 0/0과 미작업으로 표시합니다. 운영 데이터베이스, MES/PLC, 외부 AI는 연결되어 있지 않습니다.
