# ASP.NET Core 서버 배포

프론트엔드와 API를 같은 ASP.NET Core 서버에서 제공한다. `Dockerfile`은 프론트엔드를 빌드하여 백엔드의 `wwwroot/`에 복사한다. 별도 Node 서버나 Vite 개발 프록시는 운영 환경에 필요하지 않다.

## 필요한 배포 환경

- Docker 또는 ASP.NET Core Runtime 10을 실행할 서버.
- HTTPS를 제공하는 도메인과 배포 플랫폼의 인그레스/리버스 프록시.
- 계정·업무 데이터와 쿠키 키를 보존할 영구 볼륨.
- 원본 항목 명세 엑셀과 샘플 데이터가 필요한 경우 해당 파일을 제공할 읽기 전용 마운트.

기존 `chatgpt.site`는 Cloudflare Workers 기반이므로 이 .NET 이미지나 DLL을 그대로 실행하지 못한다. 기존 도메인을 유지하려면 별도 .NET 서버를 마련하고 프론트와 API 요청을 연결할 구성이 필요하다. Sites 공개 설정과 앱 내부 사용자 역할은 별개다.

## Docker

저장소 루트에서 `docker build -t ax-block-monitor:latest .`를 실행한다. 관리자 아이디와 비밀번호(12자 이상)는 배포 플랫폼의 런타임 환경변수 `AX_ADMIN_LOGIN`, `AX_ADMIN_PASSWORD`로 설정한다. 값은 이미지나 소스에 넣지 않는다. 최초 계정이 이미 저장되어 있으면 이 변수로 기존 계정이 변경되지 않는다.

로컬 Docker 확인 예시 (환경변수 값은 현재 셸에 미리 설정):

```sh
docker run -d --name ax-block-monitor \
  -p 127.0.0.1:8080:8080 \
  --env AX_ADMIN_LOGIN --env AX_ADMIN_PASSWORD \
  --mount type=volume,src=ax-block-state,dst=/var/lib/ax \
  --mount "type=bind,src=$PWD/엑셀 파일,dst=/app/엑셀 파일,readonly" \
  ax-block-monitor:latest
```

필요 파일은 `01_조선_데이터참고명세서.xlsx`, `02_조선_샘플데이터.xlsx`다. 엑셀은 Git/이미지에 포함하지 않는다. 샘플 없이 대시보드는 빈 상태로 열 수 있으나 항목 명세가 없으면 CSV 검증·적재를 사용할 수 없다. 서버의 컨테이너 사용자 UID가 파일과 영구 볼륨을 읽고 쓸 수 있어야 한다.

서버 배포 시 플랫폼 포트를 8080으로 설정하고 `/var/lib/ax`를 영구 볼륨에 연결한다. HTTPS와 프록시 신뢰 범위는 실제 배포 플랫폼의 구성을 확인하여 설정한다. 현재 코드는 단일 프로세스의 파일 저장을 사용하므로 같은 상태 파일을 여러 인스턴스가 동시에 수정하는 구성으로 확장하지 않는다.

## Docker 없이 빌드

```sh
cd app/frontend
pnpm install --frozen-lockfile
pnpm build
cd ../..
dotnet publish app/backend/AxBackend.csproj -c Release -o artifacts/server
```

`app/frontend/dist/`의 내용을 `artifacts/server/wwwroot/`에 복사한다. 실행 디렉터리를 `artifacts/server`로 설정하고 `dotnet AxBackend.dll`로 실행한다. 이 경우에도 `AX_STATE_PATH`, `AX_KEY_DIR`를 영구 저장 경로로 지정한다. 엑셀 로딩은 서버 ContentRoot에서 두 단계 위의 `엑셀 파일/`을 사용하므로 배포 폴더 구조를 보존한다.

## 배포 검증

1. `/`가 로그인 화면 HTML을 반환하는지 확인한다.
2. `/api/auth/me`가 HTML 대신 JSON을 반환하고 `Cache-Control: no-store`인지 확인한다.
3. 관리자 로그인과 설정의 사용자·권한·감사 조회를 확인한다.
4. 정상 CSV 저장, 오류 CSV 거부, 다중 파일 전체 취소를 확인한다.
5. 로그아웃 후 `/api/data`가 401인지 확인한다.
6. 서버 재시작 후 계정·데이터·쿠키 키가 유지되는지 확인한다.
